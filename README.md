ICE3BS03LJG-Based Forward Converter

Project Description
Designed and developed a high-voltage isolated DC-DC forward converter using the Infineon ICE3BS03LJG PWM controller. The project focuses on converting 325 V DC input into a regulated 110 V DC output with a target power rating of 550 W.

Key Development Activities
- Developed an isolated forward converter power stage.
- Implemented PWM switching control using ICE3BS03LJG.
- Designed high-frequency transformer and MOSFET switching circuits.
- Implemented TL431 and PC817-based closed-loop feedback regulation.
- Developed snubber and gate-drive circuits for switching control.
- Performed hardware testing, output regulation and load evaluation.
